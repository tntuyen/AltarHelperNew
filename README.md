# AltarHelperNew
Highlights the best option from Primordial Altar based on a Filter.
The plugin use a system of Weight to calculate the bes option.

> Fork of [bruno105/AltarHelper](https://github.com/bruno105/AltarHelper) (original GUI/settings kept), with the Altar mod list synced against [MrVISKman11/AltarHelper](https://github.com/MrVISKman11/AltarHelper): added mods that are missing and removed outdated/renamed ones.

How to use:

1. Start Plugin.  
2. Configure the weight of mods inside plugin settings
3. Have fun.



If you want a premade config put the [altarSettings](AltarHelperNew_settings.json) on (HUD FOLDER)/config/global/AltarHelperNew_settings.json
